What makes it different

Row-level undo

Every changed row is captured by the database itself. Undo restores parents before children and refuses rather than overwrite anyone's later writes. There is no point-in-time restore that loses a day of data.

Agents hold no credentials

Agents get a URL and a key. Database passwords and the approver key live only in the gateway.

PostgreSQL's own parser

An AST hard gate, not regex: one statement, schema-qualified writes, allowlisted pure functions only.

Built for security review

Hash-chained, append-only ledger. Least-privilege roles, refused at startup otherwise. Approvals from the CLI, the API, Slack, or company SSO.

Works with your agents

Any MCP client that speaks Streamable HTTP: Claude Code, Cursor, and custom agents. Setup is one command:

claude mcp add --transport http undogate https://your-gateway/mcp --header "Authorization: Bearer $AGENT_KEY"

Overhead: about 5 ms for a read and about 18 ms for a captured, undoable write. Agent turns take seconds.
